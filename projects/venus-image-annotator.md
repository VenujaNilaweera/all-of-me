# Venus Image Annotator

Standalone Python application for dataset annotation.

## Scope
Provide a desktop tool to draw bounding boxes on images and save annotations
in the exact YOLO format, for training real-time detection models.

## Technical details
- Bounding-box drawing UI, built with **PyQt5 + OpenCV**.
- Annotations saved in YOLO format (class + normalized xywh).
- Integrated with YOLO models for real-time human detection.
- Also referred to as "VIA" — portable YOLO-format image annotation tool
  on the LinkedIn Projects list.
