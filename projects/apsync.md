# APsync

Python-to-Arduino bridge for tasks such as motor control.

## Scope
Interface Python with Arduino boards so higher-level Python code can drive
low-level hardware (e.g. motors) reliably.

## Technical details
- Modular architecture.
- Username-based authentication.
- Auto-reconnection on link loss.
- Direct register manipulation using AVR C on the microcontroller side.
