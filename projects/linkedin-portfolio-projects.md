# Other LinkedIn Portfolio Projects

Smaller projects on the LinkedIn Projects list, being written up one at
a time. Kept together here since each is a short, mostly-closed entry;
split into its own file if one grows.

## Piezo MIDI octopad
For FL Studio: 8 velocity-sensitive pads, Arduino, USB MIDI.

## PID soldering station (built 2022)
Thermistor feedback, time-proportioning control, auto-off after 1 hour
idle.

## "Design and Prototype" course team robot
3-in-1 vacuum/sweep/mop robot with a resin 3D-printed impeller, Bluetooth
plus autonomous PID zigzag control, reused-airflow mop drying.

## VLSI Design labs
CMOS ring oscillator and current-starved VCO in Cadence Virtuoso
(group 07).

## Geosentinal
ESP32/Arduino plus Python environmental/geospatial monitoring.
GitHub: VenujaNilaweera/Geosentinal.

## AUTOBOT-X
Autonomous mobile manipulation robot (ESP32, PID navigation, IR/color
sensing, servo gripper), with Pansilu Harshan and Jeewantha Rathnayaka.

## AudiFocus
Windows Python utility that auto-ducks background audio when another app
plays sound and restores it afterward; per-app trigger selection,
optional auto-start on boot.
